Seed Hypermedia · editor explorations

One document, six editors.

Each editor loads the same real Seed document through a thin adapter. Edit freely: nothing is published. The panel next to the editor shows the changes a save would send. An untouched document shows none.

Document to open

Every editor opens this document.

    Things to try

    1. Type @ to mention an account, or [[ to link a document.
    2. Press Tab and Shift+Tab to nest and un-nest blocks.
    3. Paste a YouTube link, or text copied from another site.
    4. Bold a word after an emoji, then check that the change covers only that word.
    5. Open the same document in two editors and compare the changes they report.
